# Rutina core

App Android personal con la rutina diaria de core y pelvis neutra (psoas, puente de glúteo, dead bug, plancha y gato-camello) y un widget para la pantalla de inicio.

- **App:** animaciones de cada ejercicio, modo guiado con temporizador, voz y de 1 a 6 rondas. Funciona sin internet.
- **Widget:** muestra si la rutina de hoy está hecha, la racha de días seguidos y un botón para empezar.

## Descargar

Última versión: [rutina-core.apk](../../releases/latest/download/rutina-core.apk)

Cada cambio que se sube a `main` compila un APK nuevo y lo publica en *Releases*. Se instala encima del anterior sin perder la racha.
